# Plugin composition

Concrete dependency wiring, request execution, settings connection and reader resource lifecycles. Native storage algorithms and renderer internals belong to adapters.

Close the native access gate synchronously before asynchronous connection cleanup. Own each resource by the startup that created it; superseded starts must not publish Ready or retain authority. Reader failure may degrade display but cannot cause a saved write to repeat. Use a live trusted main window for child-note validation.

Cover rapid enable/disable/reconnect, failed startup, teardown failures, superseded status, missing renderer, and separate source-editor/strict formatted viewer evidence.
