# Local request/result transport

Dedicated-directory publication, scanning, session ownership, and Gecko filesystem adaptation. No direct library edits or shared MCP policy changes.

Validate opaque filenames and bounded complete JSON before dispatch. Keep partial files inert and final identities create-only. Descriptor selects the active session; its matching status owns enabled state. Check ownership at final dispatch; already dispatched operations remain durable even if sessions change. Never auto-copy stale requests.

Cover partial/malformed files, wrong profile/session, symlink/path escape, oversize content, disabled dispatch, concurrent replacement, and truthful publication failures. Do not claim OS no-follow guarantees from path checks.
