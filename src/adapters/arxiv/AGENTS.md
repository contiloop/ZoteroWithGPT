# arXiv acquisition

Bounded source metadata and PDF retrieval behind typed ports, plus evidence-based candidate selection. No native library mutation or production registration belongs here.

Construct HTTPS requests only from validated arXiv identities. Check every redirect and final destination; enforce byte, time, and redirect limits before unbounded allocation. Treat XML and PDF content as untrusted data. Honor rate limits without automatic retry or alternate-route bypass.

Resolve a single concrete article version before import. Never infer verified PDF identity from a title or URL alone. Ambiguous parents, conflicting versions, and unverified attachments require explicit selection. Preserve candidate data rather than choosing the first match.

Exercise hostile URLs, malformed feeds, external entities, limits, cancellation, service failures, and duplicate/version policy with controlled tests. Real metadata and native PDF acceptance remain separate required checks.
