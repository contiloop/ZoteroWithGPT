# ChatGPT study-save plugin

Portable workflow source for explicitly selected ChatGPT Web conversations using the existing Mac Safe Files app. The plugin stores only a bridge root in its separate personal configuration; portable artifacts contain no private paths, sessions, credentials, or study history.

The user manually saves the paper and PDF in Zotero before study. Selection plus one official arXiv URL authorizes only local discovery and PDF reading; it never authorizes import, download, repair, or a native write.
