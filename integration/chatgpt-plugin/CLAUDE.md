# ChatGPT plugin

This explicitly selected Web plugin studies a manually saved local PDF. Only
a later specified save authorizes native records; organize, summarize, and copy
requests have different intended outputs. Keep the paper in accessible
conversation context, never global plugin configuration. Portable source is
deliberately unconfigured: it contains no app ID, bridge root, account export,
or generic file client. Private configuration adds only a verified dedicated
MCP app binding while preserving account presentation.

`skills/zotero/resources/workflow.md` owns behavior. Schemas and
examples are bundled from the shared contract, not rewritten here. Static
scenario validation cannot establish actual model or reader behavior.
